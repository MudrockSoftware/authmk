# Security policy

authmk handles authentication for other people's users, so security reports
get priority over all other work.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub:
<https://github.com/MudrockSoftware/authmk/security/advisories/new>

Don't open a public issue for a vulnerability. Include what you found, how to
reproduce it, and which versions are affected. We will confirm receipt, keep
you updated while we fix it, and credit you in the release notes unless you
prefer otherwise.

## Supported versions

authmk is in early development (0.x). Security fixes go into the latest
release only.
